# snapszer-solver

A touch companion for a four-player game of snapszer. You enter what happens at
the table; whenever it is your turn, every choice gets a table of how the game
is likely to end. It is a static page with no backend: once loaded, it runs
entirely in the browser and works offline.

Live at <https://alkenderesi.github.io/snapszer-solver/>.

## How it works

- **Rules.** `src/engine` is a TypeScript port of the
  [snapszer](https://github.com/alkenderesi/snapszer) Python library. The tests
  replay games generated by that library and require identical legal moves and
  outcomes.
- **What you can know.** The follow rules are strict, so every card an opponent
  plays says exactly which cards they cannot hold. `src/solver/knowledge.ts`
  tracks that, and `src/solver/deals.ts` numbers every deal still consistent
  with it. Deals are drawn straight from that list, so no iteration is wasted
  on an impossible one.
- **Perfect play.** Each drawn deal is solved exactly (`src/solver/minimax.ts`,
  alpha-beta with a transposition table): everyone plays their best with all
  cards face up. One iteration scores every choice on the same deal, so all
  choices always have the same number of iterations.
- **Tables.** A column per player (T, B, P, A), a row per score (0 to 3), each
  cell the percentage of iterations. A decision runs for 1,000,000 iterations,
  or until every consistent deal has been visited, in which case the table is
  exact. The table of the choice that scores T the most on average is framed;
  choices that tie are all framed.

Perfect play assumes everyone sees every card, so the percentages lean towards
extreme scores. Trust the ranking of the choices more than the numbers.

## Using it

Seats are T (you, bottom), B (right), P (top) and A (left), played in that
order. A tap counts straight away.

1. Tap the card-back of whoever starts.
2. If you start: pick your first three cards, choose the adu, pick your other
   three. Otherwise: enter the adu the starter called, then your six cards.
3. Enter each card as it is played, on the grid at that player's seat. A Felső
   or Király that could be led from a pair asks how it was played: plain, or
   with the announcement, marked 20 or 40. A card that is the only one possible
   is entered for you.

The arrow undoes the last tap, along with any cards entered for you after it.
The circular arrow starts over, after a confirming tap. The game is saved in
the browser, so reloading resumes it.

## Development

Needs Node 26.

```sh
npm install
npm run dev        # local server
npm test           # rules, solver and app-state tests
npm run lint       # oxlint and prettier
npm run typecheck
npm run build      # production build in dist/
npm run bench      # solver throughput on one thread
```

`tools/gen_fixtures.py` regenerates the test games from the Python library:

```sh
PYTHONPATH=~/Projects/snapszer python3.14 tools/gen_fixtures.py > tests/fixtures/games.json
```

Pushing to `main` runs the checks and, if they pass, deploys to GitHub Pages.
